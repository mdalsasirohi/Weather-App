🌤️ Weather App

A responsive weather application built using **HTML, CSS, and JavaScript**. The app allows users to search for a city and displays current weather information by fetching data from a weather API.

✨ Features

* 🌍 Search weather by city name
* 🌡️ Displays current temperature, min and max temperatures
* ☁️ Shows current weather conditions
* 💨 Displays wind speed
* 💧 Displays humidity
* 📍 Displays the searched city
* 🔄 Fetches weather data dynamically using an API
* 📱 Responsive design for different screen sizes

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Weather API
* Fetch API

🚀 How to Run

1. Clone this repository
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a city name in the search bar.
5. View the current weather information for the selected city. 🌤️

🔌 API

This project uses a **weather API** to retrieve current weather data.
When a user searches for a city, the application sends a request to the API and uses the returned JSON data to display the relevant weather information.
